# Dataset Metadata



##### Overview

This ZIP archive contains multiple cleaned and processed datasets related to economic indicators in Switzerland and the European Union.



The datasets include information on:

\- Exchange rates

\- Gross Domestic Product (GDP)

\- Inflation (CPI)

\- Unemployment



##### Files included in the archive



1\. CHF\_EUR\_2000-25\_fixed.csv

&nbsp;	Description: historical time series of the exchange rate between Swiss Franc (CHF) and Euro (EUR) from 2000 to 2025. Likely variables include date/year and exchange 	rate value.



&nbsp;	Main metric: CHF/EUR exchange rate – value of 1 EUR expressed in CHF (or vice versa, depending on dataset definition).



2\. gdp\_eu\_pulito.csv

&nbsp;	Description: cleaned dataset containing Gross Domestic Product (GDP) data for European countries.



&nbsp;	Main metric: GDP – total value of goods and services produced.



3\. ipc\_eu\_pulito.csv

&nbsp;	Description: cleaned dataset containing Consumer Price Index (CPI / inflation) data for European countries.



&nbsp;	Main metric: CPI / Inflation index – measures changes in the general price level of goods and services.



&nbsp;	Unit of measure: index value (base year = 100) or percentage variation, depending on dataset structure.



4\. merged\_unemployment\_ch\_eu.csv

&nbsp;	Description: merged dataset containing unemployment statistics for Switzerland and European Union countries.



&nbsp;	Main metric: unemployment rate – percentage of the labor force that is unemployed.



Unit of measure: percentage (%)



Time coverage varies by file but mainly spans the 2000–2025 period.
