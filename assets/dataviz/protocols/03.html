Protocol of the Well-Being changes in Europe:

The visualization is a grid of line charts showing thrends of the single indicators used to compute the well-being index for Switzerland. It is used to show the small impact that crisis had on Switzerland.

data used for the visualization can be downloaded as a CSV file in the previous page.

The initial data is the same as before and can be found on the footer of the first map.

Preprocessing steps:

1. Starting from the dataset preprocessed for the map.

2. Filtered data only for Switzerland.

3. Visualization: The processed data was visualized using a grid of line charts, where each chart represents a different indicator over time. The x-axis represents the years, while the y-axis represents the normalized values of each indicator. Each chart is labeled with the corresponding indicator name for clarity.

The visualization allows users to understand the change in swiss indicators over time and see if there are some correlations with crisis periods or other events searched by the user himself.
