# Dataset Metadata



##### Overview

Dataset of changes in the well-being index for different countries/regions after three major events:

* Global Financial Crisis (2008–2010)
* COVID-19 pandemic
* War in Ukraine



Each row represents a country/area; columns report the index variation for each event.

We have 40 observations and 4 features



##### Variables

Reference area (string) – Country or geographical area name

crisis\_08\_10 (float) – Change in well-being index during 2008–2010

crisis covid (float) – Change in well-being index during COVID-19

ukrain\_war (float) – Change in well-being index after the Ukraine war



##### Unit of measure

Index variation --> positive = increase in well-being, negative = decrease
