Protocol of the Well-Being changes in Switzerland:

The visualization is a map of Europe showing for every different crisis the change in the well-being index between the start and the end of the crisis period. It is used to show the different impact in the various European countries and to comment on the findings.

data used for the visualization can be downloaded as a CSV file in the previous page.

The initial data is the same dataset as before and can be found on the footer of the first map, always the OECD dataset is used.

Preprocessing steps:

1. Starting from the dataset preprocessed for the map.

2. selection of the timestamp for every crisis (start and end date). 2007-2010 for the Great Recession, 2020-2022 for the Covid-19 Pandemic and 2022-2023 for Ukraine.

3. Visualization: The processed data was visualized using a map of Europe, where each country is colored based on the change in the well-being index during the selected crisis periods. A diverging color scale was used to represent positive and negative changes.

The visualization allows users to understand the changes that happend in diverse countries and with the additional help of the radial chart it can be used to analyze singular countries and what made the index change.
