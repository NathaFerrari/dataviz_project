# Dataset Metadata



##### Overview

This dataset contains the overall well-being index for multiple countries over time.

Each row represents a country or geographical area, while each column (from 2006 to 2024) reports the value of the composite well-being index for that year.



The dataset includes 40 observations (countries/areas) and 20 features.



##### Variables

\- Reference area (string): name of the country or geographical area.

\- 2006 – 2024 (float): annual value of the composite well-being index for the corresponding year.



##### Index value (normalized):

\- Ranges between 0 and 1.

\- Values are comparable across countries and years.

\- Changes over time represent improvements or deteriorations in overall well-being.



##### Missing Values

Some recent years (e.g., 2023–2024) contain missing values (NaN) for certain countries due to data availability delays.
